# Key prompts

The main prompts used to build each module. Each prompt is written before the module's work starts and run as written, so this file shows what the tools were actually asked to do. Follow-up corrections are noted under the prompt they belong to.

## Structure

Every prompt uses these sections:

- **Goal:** the outcome in one or two sentences.
- **Context:** the relevant files and what already exists.
- **Requirements:** what to build or change.
- **Constraints:** what to avoid, and which libraries or patterns to use.
- **Done when:** the tests or checks that prove it works.
